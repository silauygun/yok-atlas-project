
# YÖK Atlas Projesi

## Proje Hakkında

Bu proje, Türkiye'deki üniversite ve bölüm tercih eğilimlerini veri madenciliği yöntemleriyle analiz etmeyi amaçlamaktadır.

## Projenin Amacı

Üniversite ve bölümlere ait verileri inceleyerek öğrencilerin tercih süreçlerine yardımcı olacak anlamlı sonuçlar elde etmek.

## Analiz Edilecek Veriler

- Üniversite isimleri
- Bölüm isimleri
- Kontenjan bilgileri
- Taban puanları
- Başarı sıralamaları

## Kullanılacak Teknolojiler

- Python
- Pandas
- Matplotlib
- Git ve GitHub

Proje geliştirme aşamasındadır.
